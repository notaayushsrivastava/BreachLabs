STEP 1

Google Antigravity MCP Configuration

Add the BreachLabs Streamable HTTP MCP server to your Antigravity agent configuration (e.g. in ~/.gemini/antigravity/mcp/BreachLabs/).

~/.gemini/antigravity/mcp/BreachLabs/mcp.json 
{
  "mcpServers": {
    "breachlabs": {
      "url": "http://127.0.0.1:8000/mcp",
      "transport": "streamable-http"
    }
  }
}
STEP 2

Install Security Skill from skills.sh

Install the BreachLabs skill directly into your agent environment using the universal skills.sh package runner with npx, or copy the universal SKILL.md.

Terminal — Universal Skill CLI (skills.sh)
$npx skills add breachlabs
# Installs breachlabs autonomous security engineering skill from skills.sh

Seven bounded tools, zero open shells.

BreachLabs exposes an allowlisted set of structured tools to your agent. Each tool performs one specific security operation and returns structured JSON evidence.

breachlabs_surface_map

Enumerates all HTTP routes, form inputs, JSON endpoints, and authentication flows on the target.

Inputtarget_url
OutputRouteTree JSON
breachlabs_sast_scan

Performs AST-level taint tracking, secret scanning, and unsafe pattern matching across the repository.

Inputrepo_path, rules
OutputTaintSinks[]
breachlabs_dast_probe

Executes scoped runtime HTTP probes against the isolated sandbox service to observe response behavior.

Inputroute, method, payload
OutputHTTPResponse
breachlabs_verify_exploit

Dispatches deterministic reproduction check to confirm whether suspected issue is reachable and exploitable.

Inputfinding_id, probe
OutputVerificationProof
breachlabs_generate_patch

Synthesizes targeted code diff remediation targeting the vulnerable code path rather than surface filtering.

Inputfinding_id, file
OutputGitDiff
breachlabs_retest_patch

Replays the exact verification probe against the updated application commit to measure resolution.

Inputfinding_id, patch_ref
OutputPASS / FAIL
