{% with label="02 — The security loop" %}{% include "components/section-label.html" %}{% endwith %}

Build. Discover. Test. Investigate. Verify. Fix. Retest.

BUILD — Create or receive the application.

DISCOVER — Map routes, forms, APIs, auth flows.

TEST — SAST, dependency, secret, DAST checks.

INVESTIGATE — Correlate results with evidence.

VERIFY — Targeted checks before certainty.

FIX — Explain remediation, prepare targeted fix.

RETEST — Repeat assessment, confirm resolution.
